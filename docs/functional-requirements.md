#Functional Requirements 

#Authentication  -System should : allow users to log in ,allow users to log out ,allow managers to create user accounts ,support role-based access control 

#Driver Management - System should : allow system managers to register drivers ,shall allow managers to update driver information ,allow managers to suspend drivers ,display driver details ,allow searching for drivers 

#Vehicle Management -System should: allow managers to register vehicles ,shall allow updating vehicle information , shall archive vehicles ,shall display vehicle information ,allow for searching of vehicles

#Vehicle requests - System should : allow drivers to submit requests ,allow managers to review pending requests ,allow fleet managers to reject/approve requests 

#Trip Management - System should : drivers to start or end trips ,allow drivers to complete trips ,allow driver to record trip information ,shall display trip history 

#Dashboard - System should : display fleet statistics ,display vehicles currently assigned ,display requests by status ,shall display upcoming maintenance, shall display expenditure
